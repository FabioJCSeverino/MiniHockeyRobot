# Mini Hockey Robot

A small autonomous/remote-controlled Mini Hockey robot developed at GERM — UDESC.

The project combines mechanical design, PCB development, electronics,
embedded programming, and robot control.

## My Contributions

- PCB design using EasyEDA
- Electronic integration
- Embedded C/C++ programming
- Robot control logic
- Hardware/software integration

## Hardware

ESP32 - 38 pins, Driver Motor H-Bridge TB6612FNG, LM2596 DC Step Down, 2 * 3,7V 380mAh batteries, 2 * DC N20 Motors

## Software

The arduino code creates a bluetooth conection, and controls the MicroHockey's movement. The robot can be controlled via cellphone.
